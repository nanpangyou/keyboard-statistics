# 键盘使用统计（keyboard-statistics）

一个只在本机运行的小工具：统计你**按了哪些键、按了多少次、什么时间按的、用过哪些快捷键**，
用热力图和趋势图展示。**不记录你输入的任何内容。**

> 使用手册版本：**v0.1（开发中）**
> 每个发布版本都会重写本手册，与 `CHANGELOG.md` 中对应版本保持一致。

---

## 1. 它能做什么

- 统计单键频次，排行 TOP 10
- 统计常用快捷键（复制 / 粘贴 / 切换窗口 / 截屏…），排行 TOP 10
- 键盘热力图：一眼看出哪些键按得最多
- 今日 / 近 7 天 / 近 30 天 / 全部 四种时间范围
- 活跃时长、日均按键、峰值、24 小时时段分布
- 导出 CSV 自己分析

## 2. 它绝对不做什么

这是本工具的核心承诺，也是它敢常驻后台的原因：

| 不做 | 说明 |
|---|---|
| 不记录按键内容 | 库里只有「键码 + 次数 + 日期小时」，没有任何文本 |
| 不记录按键顺序 | 组合键只记「哪几个键同时按下」，不记先后 |
| 不记录窗口标题 / 应用名 | 不知道你在用什么软件 |
| 不联网 | 无任何网络代码，数据只在本机 |
| 不静默自启 | 自启默认关闭，需你手动勾选 |

数据文件位置：`%LOCALAPPDATA%\keyboard-statistics\stats.db`

## 3. 系统要求

- Windows 10 / 11（64 位）
- 无需安装，单个 exe，双击即用
- 无需管理员权限

## 4. 安装与启动

1. 下载 `keyboard-statistics-v0.1.0.exe`
2. 放到任意目录（建议固定位置，**移动后开机自启会失效**）
3. 双击运行

首次启动会：

- 弹出一个说明窗口，讲清「统计什么 / 不统计什么 / 数据在哪」
- 同时发一条系统通知
- **立即开始统计**，不需要你再点任何按钮

## 5. 界面

### 顶部栏

- 时间范围：`今日 / 近 7 天 / 近 30 天 / 全部`
- 右侧状态：`● 采集中` / `● 已暂停`

### 概览

总按键数、活跃时长、日均按键、峰值、按键 TOP 10、快捷键 TOP 10、24 小时时段分布。

### 热力图

QWERTY 全键盘键位图，颜色越深按得越多。鼠标悬停看具体次数与占比。

### 设置

暂停/继续采集、清空数据、导出 CSV、开机自启、关于（版本、数据目录）。

## 6. 快捷键是怎么统计的

**只要按下的键里有 Ctrl / Alt / Win 中的任意一个，就算一次组合键。**

| 你会看到 | 举例 |
|---|---|
| ✅ 计为组合 | `Ctrl+C` `Ctrl+V` `Alt+Tab` `Alt+A` `Win+D` `Ctrl+Shift+T` |
| ✅ 计为组合（Shift + 非字符键） | `Shift+←` `Shift+回车` `Shift+Tab` |
| ❌ 不计为组合 | `Shift+A`、`Shift+1`（那是正常打字，不是快捷键） |
| ❌ 不计为组合 | 单个按下的 `Ctrl` / `Shift` / `Alt` / `Win` |

组合键与单键**分别统计、互不冲突**：按一次 `Ctrl+C`，`C` 计 1 次，`Ctrl` 计 1 次，`Ctrl+C` 也计 1 次。

> 记录 `Ctrl+V` 只代表「你按了一次粘贴这个动作」，工具**不知道你粘贴了什么**。

## 7. 开机自启

在设置里勾选「开机自启」后：

- 程序会在下次开机时自动启动
- 启动时**窗口最小化**，任务栏可见，不打扰你
- 随时取消勾选即可彻底移除

如果你之后移动或重命名了 exe，自启会指向旧路径而失效，设置页会提示你重新勾选。

## 8. 导出数据

设置页点「导出 CSV」，选择保存位置，会生成两个文件：

- `keyboard-stats-<起>-<止>_keys.csv`：日期、小时、键码、键名、次数
- `keyboard-stats-<起>-<止>_combos.csv`：日期、小时、组合、次数

UTF-8 with BOM 编码，Excel 直接打开不乱码。

## 9. 已知限制

- **以管理员身份运行的窗口**（如任务管理器）中的按键统计不到，这是 Windows 权限隔离的必然结果
- `Ctrl+Alt+Delete`、`Win+L` 这类系统保留组合任何键盘钩子都收不到
- 部分杀毒软件可能对全局键盘钩子报警（本程序不混淆、不加壳）
- 活跃时长是估算值：相邻按键间隔 ≤ 60 秒才算连续

## 10. 常见问题

**Q：会不会记录我的密码？**
A：不会。程序只记录「哪个键被按了多少次」，不保留任何顺序和文本，无法还原出任何输入内容。

**Q：占用大吗？**
A：常驻内存约几十 MB，数据库一年也就几十万行，几 MB 级别。

**Q：关掉窗口就不统计了吗？**
A：是的。v0.1 关闭窗口即退出并停止统计。想要关窗后继续统计，等后续版本的托盘常驻功能。

**Q：数据能删吗？**
A：设置页「清空数据」一键删除，不可恢复。
