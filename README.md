# ⌨️ 键盘使用统计（keyboard-statistics）

一个只在本机运行的小工具：统计你**按了哪些键、按了多少次、什么时间按的、用过哪些快捷键**，
用热力图和趋势图展示。**不记录你输入的任何内容。**

> 📖 使用手册版本：**v0.2.0**
> 每个发布版本都会重写本手册，与 [CHANGELOG.md](CHANGELOG.md) 中对应版本保持一致。

---

## ✨ 它能做什么

- 🔢 统计单键频次，排行 TOP 10
- 🎯 统计常用快捷键（复制 / 粘贴 / 切换窗口 / 截屏…），排行 TOP 10
- 🗺️ 键盘热力图：一眼看出哪些键按得最多
- 📅 时间范围：今日 / 近 7 天 / 近 30 天 / 全部
- ⏱️ 活跃时长、日均按键、峰值、24 小时时段分布
- 📤 导出 CSV 自己分析

## 🔒 它绝对不做什么

这是本工具的核心承诺，也是它敢常驻后台的原因：

| 不做 | 说明 |
|---|---|
| 🚫 不记录按键内容 | 库里只有「键码 + 次数 + 日期小时」，没有任何文本 |
| 🚫 不记录按键顺序 | 组合键只记「哪几个键同时按下」，不记先后 |
| 🚫 不记录窗口标题 / 应用名 | 不知道你在用什么软件 |
| 🚫 不联网 | 无任何网络代码，数据只在本机 |
| 🚫 不静默自启 | 自启默认关闭，需你手动勾选 |

📁 数据文件位置：默认 `%LOCALAPPDATA%\keyboard-statistics\stats.db`（也就是 `C:\Users\你的用户名\AppData\Local\...`）。
想让数据跟着程序走、或者放到别的盘，见下面的 [数据放在哪](#-数据放在哪)。

## 💻 系统要求

- Windows 10 / 11（64 位）
- 单个 exe，双击即用；也可以装安装包（见下）
- 无需管理员权限
- 🖥️ **不需要显卡加速，也不要求 OpenGL**：界面是 Windows 原生窗口，云桌面 / 远程桌面里照样正常显示

## 🚀 安装与启动

**两种方式，任选其一。**

### 方式一：免安装（单文件）

1. 下载 `keyboard-statistics-v0.2.0.exe`
2. 放到任意目录（建议固定位置，**移动后开机自启会失效**）
3. 双击运行

### 方式二：安装包

1. 下载 `keyboard-statistics-0.2.0-setup.exe`
2. 双击，安装向导里可以**自选安装目录**（装到 `D:\` 这种非系统盘也完全没问题）
3. 按当前用户安装，**不弹 UAC**、不写系统目录；卸载时走「设置 → 应用」
4. 向导里有一个「把数据保存在程序目录（便携模式）」的勾选项，含义见下一节

> 🌐 安装向导目前是**英文**界面（Inno Setup 官方包不含简体中文语言文件，没采用来源不明的第三方翻译）。
> 需要中文的话只能先等官方语言包补齐，主程序界面不受影响。

首次启动会：

- 💬 弹出一个说明框（只弹这一次），讲清「统计什么 / 不统计什么 / 数据在哪」，点「确定」即可
- ▶️ **立即开始统计**，不需要你再点任何按钮

> 首次启动**不发系统通知**、也不出现托盘图标；「正在采集」由窗口顶部和底部的 `● 采集中` 指示。

## 📁 数据放在哪

程序按下面的顺序决定数据目录，**先满足的生效**：

| 顺序 | 位置 | 怎么触发 |
|---|---|---|
| 1️⃣ | 你自己指定的目录 | 设置页「更改数据目录…」 |
| 2️⃣ | `<程序目录>\data` | 便携模式：exe 旁边有 `portable.txt`（安装时勾选即自动创建） |
| 3️⃣ | `%LOCALAPPDATA%\keyboard-statistics` | 默认，上面两条都不满足时 |

设置页「关于」里会直接写着当前用的是哪个目录、属于哪种存放方式。

几点要说明：

- 🧳 **便携模式**是给你「数据跟程序一起走」用的（装 D 盘、放 U 盘都行）。
  如果程序目录写不进去（典型情况：装在 `C:\Program Files`），程序会**自动回退**到用户目录，
  并在设置页把存放方式显示成「用户数据目录」——不会因为写不进去而起不来。
- 💾 **换数据目录**：点「更改数据目录…」选一个新目录，程序会先检查能不能写、
  以及里面有没有旧的统计数据（有就拒绝，避免覆盖）。确认后程序退出，
  **下次启动时把旧数据搬过去**，旧位置不会留副本。
  之所以要重启，是因为运行中数据库文件被占用，Windows 不允许移动。
- 🗑️ **卸载**不会静默删你的统计数据：便携模式下如果 `<程序目录>\data` 里有数据，
  卸载器会先问一句。

## 🖥️ 界面

一个标准的 Windows 原生窗口（微软雅黑，跟随系统 DPI 缩放，高分屏不发虚），
初始 900×680，最小 800×600，可以随意拖拽缩放。窗口从上到下分三块：

### 顶部工具栏

- 🕐 时间范围（单选，默认「今日」）：`今日 / 近 7 天 / 近 30 天 / 全部`
- 🔴 采集状态：`● 采集中`（绿点）/ `● 已暂停`（灰点）/ `● 采集中断`（红点，一般是被安全软件拦了钩子）

切换时间范围后，三个页面的数字**立刻**跟着变，不用刷新。

### 三个页面

| 页面 | 里面有什么 |
|---|---|
| 📊 概览 | 四张指标卡（总按键数、活跃时长、日均按键、峰值）+ 按键 TOP 10 + 快捷键 TOP 10 + 24 小时时段柱状图 |
| 🗺️ 热力图 | 一整张 QWERTY 键盘图，按当前范围的次数着色：颜色越深按得越多。鼠标悬停看键名、次数、占比，悬停的键会加描边 |
| ⚙️ 设置 | 暂停/继续采集、清空数据、导出 CSV、开机自启、关于（版本号、数据目录、打开数据目录） |

### 底部状态栏

常显当前数据范围和天数（如 `2026-10-27 ~ 2026-11-02 · 共 7 天`）、采集状态 `● 采集中` /
`● 已暂停`、最后刷新时刻；读取数据出错时在这里显示一行红字，不弹窗打断你。

### 刷新节奏

界面每 **2 秒**自动刷新一次，采集中的数字基本是「实时」的。没有数据时页面显示
「当前范围还没有数据」，不会给你画一排 0。

## 🎯 快捷键是怎么统计的

**只要按下的键里有 Ctrl / Alt / Win 中的任意一个，就算一次组合键。**

| 你会看到 | 举例 |
|---|---|
| ✅ 计为组合 | `Ctrl+C` `Ctrl+V` `Alt+Tab` `Alt+A` `Win+D` `Ctrl+Shift+T` |
| ✅ 计为组合（Shift + 非字符键） | `Shift+←` `Shift+回车` `Shift+Tab` |
| ❌ 不计为组合 | `Shift+A`、`Shift+1`（那是正常打字，不是快捷键） |
| ❌ 不计为组合 | 单个按下的 `Ctrl` / `Shift` / `Alt` / `Win` |

组合键与单键**分别统计、互不冲突**：按一次 `Ctrl+C`，`C` 计 1 次，`Ctrl` 计 1 次，`Ctrl+C` 也计 1 次。

> 🔐 记录 `Ctrl+V` 只代表「你按了一次粘贴这个动作」，工具**不知道你粘贴了什么**。

## ⚡ 开机自启

在设置里勾选「开机自启」后：

- 程序会在下次开机时自动启动
- 启动时**窗口最小化**，任务栏可见，不打扰你
- 随时取消勾选即可彻底移除

如果你之后移动或重命名了 exe，自启会指向旧路径而失效，设置页会提示你重新勾选。

## 📤 导出数据

设置页点「导出 CSV」，选择保存位置，会生成两个文件：

- `keyboard-stats-<起>-<止>_keys.csv`：日期、小时、键码、键名、次数
- `keyboard-stats-<起>-<止>_combos.csv`：日期、小时、组合、次数

UTF-8 with BOM 编码，Excel 直接打开不乱码。

## ⚠️ 已知限制

- 🔐 **以管理员身份运行的窗口**（如任务管理器）中的按键统计不到，这是 Windows 权限隔离的必然结果
- 🚫 `Ctrl+Alt+Delete`、`Win+L` 这类系统保留组合任何键盘钩子都收不到
- 🛡️ 部分杀毒软件可能对全局键盘钩子报警（本程序不混淆、不加壳）
- ⏱️ 活跃时长是估算值：相邻按键间隔 ≤ 60 秒才算连续

## ❓ 常见问题

**Q：会不会记录我的密码？**
A：不会。程序只记录「哪个键被按了多少次」，不保留任何顺序和文本，无法还原出任何输入内容。

**Q：占用大吗？**
A：常驻内存约几十 MB，数据库一年也就几十万行，几 MB 级别。

**Q：关掉窗口就不统计了吗？**
A：是的。v0.1 关闭窗口即退出并停止统计。想要关窗后继续统计，等后续版本的托盘常驻功能。

**Q：数据能删吗？**
A：设置页「清空数据」一键删除，不可恢复。
