# 统计口径（metrics）

本文是**唯一口径标准**。代码与文档冲突时以本文为准；改口径必须先改本文并更新 `CHANGELOG.md`。

所有时间一律使用**本地时区**（`time.Local`）。日期格式 `YYYY-MM-DD`，小时 0–23。

---

## 1. 一次按键（一次计数）

**定义**：某个物理键从「抬起」进入「按下」的那一瞬间，记 1 次。

**长按不重复计数**：Windows 的 `WH_KEYBOARD_LL` 对按住不放的键会持续投递 `WM_KEYDOWN`。
采集器维护一个「当前按下键集合」：

- 收到 `WM_KEYDOWN` / `WM_SYSKEYDOWN`，且 `vk` **不在**集合里 → 计数 +1，并加入集合
- 收到 `WM_KEYUP` / `WM_SYSKEYUP` → 从集合移除
- 收到重复的 `WM_KEYDOWN`（`vk` 已在集合里）→ **忽略**

**边界**：程序启动时集合为空；若用户启动程序时正按着某键（无 keyup），该键下一次真实按下
仍会被计 1 次——可接受，不做特殊处理。

**左右修饰键**：`VK_SHIFT` / `VK_CONTROL` / `VK_MENU` 不区分左右，合并计数（v0.1）。

## 2. 键名（key name）

| 类别 | 显示规则 | 例 |
|---|---|---|
| 字母 | 大写字母 | `A` `Z` |
| 数字 | 字符本身 | `1` `0` |
| 小键盘数字 | `小键盘N` | `小键盘1` |
| 功能键 | `F1`…`F24` | `F5` |
| 常用控制键 | 中文名 | `空格` `退格` `回车` `Tab` `Esc` `Shift` `Ctrl` `Alt` `Win` `CapsLock` |
| 方向键 | `↑` `↓` `←` `→` | |
| 标点 / 其他 | 取该键在 US 布局的字符，无字符则 `VK_<码>` | `;` `VK_255` |

同一个 `vk` 在任何地方都必须映射成同一个显示名，映射表放在 `internal/stats/keyname.go`。

## 3. 总按键数（total）

范围内所有按键次数之和：

```sql
SELECT COALESCE(SUM(count), 0) FROM key_count
WHERE day BETWEEN :from AND :to;
```

`今日` = `from = to = 今天`；`近 7 天` = 含今天在内往前共 7 个自然日；`近 30 天` 同理；
`全部` = 从有数据的第一天到今天。

**组合键不计入总按键数**，它是独立的第二套计数。

---

## 4. 占比（percent）

```
按键占比 = 该键次数 / 范围内总按键数
组合占比 = 该组合次数 / 范围内组合键总次数
```

两套占比分母各自独立，不可混用。显示保留整数百分比（四舍五入）。分母为 0 时显示 `0%`。

---

## 5. TOP 10

按键与组合键各自独立排名。排序规则相同：

- 按次数**降序**
- 次数相同时：按键按 `vk` **升序**，组合键按**组合名字符串升序**（保证结果稳定、可测试）

各最多 10 条。

---

## 6. 时段分布

```sql
SELECT hour, SUM(count) AS c FROM key_count
WHERE day BETWEEN :from AND :to
GROUP BY hour ORDER BY hour;
```

只统计**单键**，不含组合键。返回固定 24 个桶，没有数据的小时补 0。

## 7. 组合键（combo）

### 7.1 什么算组合键

组合键 = **同一时刻**被按住的一组键。判定发生在每次 keydown：

```
修饰集合 = {当前按下集合} ∩ {Ctrl, Shift, Alt, Win}    // 不含本次按下的键
主键     = 本次按下的键
```

成立条件（满足其一）：

1. 修饰集合包含 **Ctrl / Alt / Win 中任意一个** → 成立
2. 修饰集合**只有 Shift** → 仅当主键是「非字符键」时成立

**非字符键**的定义：主键不在以下范围内 —— 字母 `A-Z`、主数字 `0-9`、
主键盘标点（`VK_OEM_1`…`VK_OEM_3`、`VK_OEM_4`…`VK_OEM_7`、`VK_OEM_102`）。

因此：

| 按键 | 是否记为组合 | 原因 |
|---|---|---|
| `Ctrl+C` / `Ctrl+V` / `Ctrl+X` | ✅ | 含 Ctrl，主键即使是字符键也成立（复制 / 粘贴 / 剪切） |
| `Ctrl+Z` / `Ctrl+Y` / `Ctrl+S` / `Ctrl+F` | ✅ | 同上（撤销 / 重做 / 保存 / 查找） |
| `Ctrl+W` / `Alt+F4` | ✅ | 含 Ctrl / Alt（关闭） |
| `Alt+A` / `Alt+S` / `Alt+Q` | ✅ | 含 Alt，与主键是不是字母无关；应用热键（如微信 `Alt+A` 截屏）照样算 |
| `Ctrl+Shift+T` | ✅ `Ctrl+Shift+T` | 含 Ctrl |
| `Alt+Tab` | ✅ `Alt+Tab` | 含 Alt（切换窗口） |
| `Win+D` / `Win+R` | ✅ `Win+D` | 含 Win |
| `Shift+←` | ✅ `Shift+←` | 只有 Shift，但 ← 是非字符键 |
| `Shift+Enter` | ✅ `Shift+Enter` | 同上 |
| `Shift+A` | ❌ | 只有 Shift + 字符键，属于正常输入 |
| `Shift+1` | ❌ | 同上 |
| 单独按 `Ctrl` | ❌ | 主键本身是修饰键 |
| `Ctrl` 按住 + 按 `C` | ✅ `Ctrl+C` | C 是字符键，但因含 Ctrl 而成立 |

**主键本身是修饰键时永不构成组合**（单独按 Ctrl / Shift / Alt / Win 不计组合）。

**隐私说明**：记录 `Ctrl+V` 只意味着「按了一次粘贴这个动作」，不涉及粘贴了什么内容；
同理 `Ctrl+C` 不涉及复制了什么。库里永远只有「组合名 + 次数」。

### 7.2 不重复计数

- 按住 `Ctrl` 连按 3 次 `C` → `Ctrl+C` 记 **3 次**（每次 C 的 keydown 都成立一次）
- 按住 `Ctrl+C` 不放 → 只有第一次 C 的 keydown 计数，长按重复被 1 节的去重规则吞掉
- 修饰键的 keydown 本身（第一次按下 Ctrl）不产生组合，只产生一次单键计数

### 7.3 规范化名称

组合名格式：`修饰键1+修饰键2+...+主键`，修饰键**固定按 `Ctrl → Shift → Alt → Win` 顺序**排列，
主键放最后，用 `+` 连接，键名用第 2 节的映射。

例：`Ctrl+Shift+T`、`Ctrl+Alt+Delete`（Alt 在前）、`Shift+←`、`Win+D`。

### 7.4 与单键统计的关系

组合成立时：

- 主键**照常计入单键统计**（`Ctrl+C` 使 `C` +1）
- 修饰键也照常计入单键统计（使 `Ctrl` +1）
- 组合键**额外**记一条

即两套计数并存、互不扣减。总按键数只按单键统计，不重复累加组合。

### 7.5 不做的

- 链式/顺序快捷键（VSCode `Ctrl+K Ctrl+C`、Emacs 组合）→ v0.2
- 双击修饰键（双击 Ctrl 等）→ 不做
- 鼠标 + 键盘组合 → 不做

## 8. 活跃时长（active duration）

**会话定义**：把按键按时间排序，相邻两次按键间隔 **≤ 60 秒**视为同一个活跃会话；
间隔 > 60 秒则开启新会话。

```
活跃时长 = Σ (会话内相邻按键的时间差)
```

要点：

- **首个按键本身不计时长**（它是会话起点，不是间隔）
- 只有 1 次按键的会话贡献 0 秒
- 60 秒是常量 `ActiveGapThreshold`，v0.1 不可配置
- 累加在采集时完成，**不保存任何按键时间点**
- 组合键的产生同样算作「一次按键事件」，参与活跃时长计算

**跨天**：会话跨越午夜时，把间隔按两侧日期切分后分别累加。

**精度**：秒。显示为 `3 小时 12 分`（不足 1 小时显示 `12 分`，不足 1 分钟显示 `不足 1 分`）。

**已知误差**：程序在会话中途被强行结束时，最后一段（上次按键 → 结束时刻）不计入。

---

## 9. 日均按键

```
日均 = 范围内总按键数 / 范围内自然天数
```

- 自然天数 = 范围内日历天数（含两端）：`今日`=1，`近 7 天`=7，`近 30 天`=30
- `全部` = 首条数据日期 → 今天的天数（含两端，至少 1）
- 结果**向下取整**，显示千分位
- 范围为 0 天时不显示（避免除零）

---

## 10. 峰值

```
峰值 = 范围内单日总按键数的最大值
```

并列时取**日期最近**的那一天。展示为 `1,234（11-02）`。
无数据时不显示。

---

## 11. 采集状态

- `collecting = '1'` 时钩子才计数
- 暂停期间按键**不计数、不产生组合、也不计入活跃时长**
- 暂停前未 flush 的内存数据在暂停时立即 flush
- 状态存于 `meta.collecting`，重启后沿用

---

## 12. 清空数据

删除 `key_count`、`combo_count`、`day_activity` 全部行，保留 `meta`
（`installed_at` 与 `onboarded` 保留）。清空后各页回到空状态，活跃时长归零。
