# 需求说明（v0.1）

`keyboard-statistics` —— 统计本机键盘使用情况的 Windows 桌面小工具。

## 1. 目标

双击一个 exe 就能用，在后台统计你**按了哪些键、按了多少次、什么时间按的、
用过哪些快捷键**，并用热力图和趋势图直观展示。不记录任何按键内容。

### 非目标（v0.1 明确不做）

- 不记录按键内容、按键顺序、输入文本、剪贴板
- 不记录窗口标题、应用名、进程名（v0.1 不做按应用统计）
- **不做链式/顺序快捷键**（如 VSCode 的 `Ctrl+K Ctrl+C`），只统计**同时按下**的组合
- 不做云同步、账号、遥测、崩溃上报
- 不做打字速度 / WPM / 输入分析
- 不做系统托盘、全局快捷键、多语言（v0.2 候选）
- 不支持 macOS / Linux（只做 Windows）

## 2. 用户故事

1. 我想知道我今天一共按了多少次键。
2. 我想知道我最常按的是哪几个键，占多大比例。
3. 我想知道我最常用哪些快捷键（复制、粘贴、切换窗口），各用了多少次。
4. 我想看一张键盘图，一眼看出哪些键被按得最多。
5. 我想知道我在一天里什么时段打字最多。
6. 我想看最近 7 天 / 30 天的趋势。
7. 我想知道我的「活跃时长」和「日均按键」，而不是单纯的总数。
8. 我想把数据导出成 CSV 自己分析。
9. 我想随时暂停采集、一键清空所有数据。
10. 我想确认这个软件到底记了什么、没记什么。

## 3. 界面规格

单窗口，可缩放，初始 900×680，最小 800×600。

### 3.1 顶部栏

- 左侧：标题「键盘使用统计」
- 中间：时间范围切换 `今日 / 近 7 天 / 近 30 天 / 全部`（单选，默认今日）
- 右侧：采集状态指示 `● 采集中` / `● 已暂停`

### 3.2 页面一：概览

| 元素 | 说明 |
|---|---|
| 总按键数 | 当前时间范围内的按键总数，千分位显示 |
| 活跃时长 | 见 `docs/metrics.md` 定义，格式 `3 小时 12 分` |
| 日均按键 | 范围内总按键 ÷ 自然天数 |
| 峰值 | 范围内单日最高的按键数，并标注是哪天 |
| 按键 TOP 10 | 单键排行：键名 + 次数 + 占比 |
| **快捷键 TOP 10** | 组合键排行：组合名 + 次数 + 占比（占比以组合键总数为分母） |
| 时段分布 | 0–23 点的柱状图，显示各小时按键总数 |

### 3.3 页面二：热力图

- 一张 QWERTY 布局键位图（含字母区、数字区、功能区、修饰键、方向键、小键盘）
- 按当前时间范围内该键的次数着色，浅 → 深表示低频 → 高频
- 鼠标悬停显示：键名、次数、占比
- 悬停时该键高亮描边
- 无数据时整图为中性色，并提示「当前范围还没有数据」
- **热力图只反映单键次数**，组合键不参与着色

### 3.4 页面三：设置

| 项 | 说明 |
|---|---|
| 采集开关 | 「暂停采集 / 继续采集」，状态持久化 |
| 采集范围说明 | 明确写出：只记录键码、次数、时间、同时按下的组合；不记录内容 |
| 清空数据 | 二次确认后删除全部统计，不可恢复 |
| 导出 CSV | 导出当前范围为 CSV，弹出保存对话框（按键与组合键各一个文件） |
| 开机自启 | 默认关闭；勾选后写 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`，取消勾选即删除该值。**不使用 HKLM（需管理员、影响所有用户）** |
| 关于 | 版本号、数据文件位置、打开数据目录 |

### 3.5 首次启动与提醒

**默认即开始采集**，不需要用户点任何按钮。

第一次运行弹出一个说明对话框（一次性，状态记入 `meta.onboarded`）：

- 正在统计什么：按键频次、时间、常用快捷键
- **不记录什么**：按键内容、按键顺序、窗口标题、剪贴板
- 数据存在哪：`%LOCALAPPDATA%\keyboard-statistics\stats.db`，只在本机，不联网
- 怎么停：设置页「暂停采集」，或直接关闭程序
- 一个「确定」按钮（`MessageBoxW` 的原生按钮），关闭后进入主界面

说明对话框用原生 `MessageBoxW` 实现，**首次启动只弹这一次**，文案必须包含三句：

1. 「已经开始采集」——不需要你点任何按钮
2. 「只记键码与次数，不记内容」——不记录按键内容、顺序、窗口标题、剪贴板
3. 「可随时暂停」——设置页「暂停采集」，或直接关闭程序

用户确认后写 `meta.onboarded`；写入失败只记日志，不阻塞启动。

**不做系统通知气泡**：不为一个气泡引入托盘 / 通知依赖（`Shell_NotifyIcon` 那条路留到 v0.2 托盘功能一起做）。

除首次外，每次启动**不弹窗、不发通知**，但必须保持「采集可见」：

- 采集状态常显：顶部工具栏右侧 `● 采集中` / `● 已暂停`，**底部状态栏同步一行**拦住「关掉就看不到在采集」的担心
- 概览页顶部有一条常驻细提示条：「只统计按键频次与时间，不记录输入内容」+「暂停」快捷按钮

### 3.6 启动与关闭行为

- **手动双击启动**：正常显示主窗口
- **开机自启启动**（带 `--autostart` 参数）：窗口以**最小化**状态启动，任务栏可见
  （不隐藏、不进托盘），采集立即开始，用户点任务栏图标即可打开
- **点窗口关闭 = 退出程序并停止采集**，不做「关闭后仍在后台采集」
- 取舍说明：v0.1 接受「关掉就不再统计」；希望关窗后继续常驻，等 v0.2 的托盘功能

### 3.7 状态与边界

- 无数据：各页显示空状态文案，不显示 0 值图表
- 数据库损坏 / 打不开：弹出错误页，提供「备份并重建」与「退出」
- 采集被系统拒绝（钩子安装失败）：状态显示「采集中断」并给出原因

## 4. 数据模型

见 `internal/store/schema.sql`。四张表：

```sql
-- 按键维度：某天某小时某键累计次数
CREATE TABLE key_count (
  day   TEXT    NOT NULL,   -- 'YYYY-MM-DD'（本地时区）
  hour  INTEGER NOT NULL,   -- 0-23（本地时区）
  vk    INTEGER NOT NULL,   -- Windows 虚拟键码
  count INTEGER NOT NULL,
  PRIMARY KEY (day, hour, vk)
);

-- 组合键维度：某天某小时某组合累计次数
CREATE TABLE combo_count (
  day   TEXT    NOT NULL,   -- 'YYYY-MM-DD'
  hour  INTEGER NOT NULL,   -- 0-23
  combo TEXT    NOT NULL,   -- 规范化组合名，如 'Ctrl+C'、'Ctrl+Shift+T'
  count INTEGER NOT NULL,
  PRIMARY KEY (day, hour, combo)
);

-- 活跃度：每天一行，只存累计秒数与首末时刻
CREATE TABLE day_activity (
  day          TEXT PRIMARY KEY,  -- 'YYYY-MM-DD'
  active_sec   INTEGER NOT NULL,  -- 活跃秒数（口径见 docs/metrics.md）
  first_press  TEXT,              -- 'HH:MM:SS'，当天第一次按键
  last_press   TEXT               -- 'HH:MM:SS'，当天最后一次按键
);

-- 元信息
CREATE TABLE meta (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
```

`meta` 中至少包含：`schema_version`、`collecting`（'1'/'0'）、`installed_at`、`onboarded`。

## 5. 采集与写入

- 钩子：`SetWindowsHookExW(WH_KEYBOARD_LL)`，跑在 `runtime.LockOSThread` 的 goroutine + 消息循环里
- 回调里只做：去重判断（长按）、组合判断、内存累加
- 长按不重复计数：维护「当前按下集合」，keydown 时不在集合里才 +1
- 组合键：keydown 时用「当前按下集合」里的修饰键 + 本次键拼出组合名，累加
- 落库：每 30 秒或攒够 500 次按键 flush 一次，`INSERT ... ON CONFLICT DO UPDATE SET count = count + excluded.count`
- 活跃时长：内存记录上次按键时刻，间隔 ≤60s 时把该段累加进当天 `active_sec`
- 程序退出前必须 flush 一次；跨天时切分到对应日期
- 数据文件：`%LOCALAPPDATA%\keyboard-statistics\stats.db`

## 6. 导出格式

CSV，UTF-8 带 BOM（Excel 直接打开不乱码）。导出两个文件。

**按键文件** `keyboard-stats-<起>-<止>_keys.csv`：

| 列 | 示例 |
|---|---|
| 日期 | 2026-11-02 |
| 小时 | 14 |
| 键码 | 32 |
| 键名 | 空格 |
| 次数 | 1821 |

**组合键文件** `keyboard-stats-<起>-<止>_combos.csv`：

| 列 | 示例 |
|---|---|
| 日期 | 2026-11-02 |
| 小时 | 14 |
| 组合 | Ctrl+C |
| 次数 | 57 |

## 7. 隐私与红线对照

| 红线 | 本需求的落实 |
|---|---|
| 不记录按键内容 | 库里只有 vk 键码 + 次数 + 日期小时，无顺序、无文本 |
| 不记录按键序列 | 组合键只记「哪几个键同时按下 + 次数」，不记先后顺序 |
| 不联网上传 | 无任何网络代码 |
| 不隐藏采集 | 首次启动需确认；状态栏常显；设置页写明范围；可暂停/清空 |
| 不做静默自启 | 自启默认关，需用户勾选 |
| 不写敏感信息进仓库 | 配置与数据全在 `%LOCALAPPDATA%` |

## 8. 已知限制（必须在 README 与设置页说明）

- 以管理员身份运行的窗口（如任务管理器）中的按键统计不到
- **系统保留组合收不到**：`Ctrl+Alt+Delete`（安全注意序列由 winlogon 独占）、`Win+L`（锁屏）
  这类组合不会到达任何键盘钩子，属于 Windows 设计，不是 bug
- 只统计「你按了什么」，不判定「谁响应了」：应用热键（微信 `Alt+A` 截屏、输入法切换）只要按了就算，
  不管对应程序是否在运行
- 开机自启写入的是 exe 的全路径；用户移动/重命名 exe 后该值会失效，设置页检测到路径不匹配时
  提示重新勾选（不做静默修复）
- 全局键盘钩子可能被部分杀毒软件误报（不混淆、不加壳，README 如实说明）
- 睡眠 / 休眠期间的按键无法统计（本来也没有按键）
- 活跃时长为估算值，口径见 `docs/metrics.md`
- 组合键只统计「同时按下」，链式快捷键（`Ctrl+K Ctrl+C`）不统计

## 9. 验收标准（v0.1 DoD）

- [ ] 双击 exe 启动，无控制台黑框
- [ ] 首次启动有说明页，确认后开始采集
- [ ] 连续打字 1 分钟后，概览页总数、按键 TOP 10 正确
- [ ] 长按某键 3 秒，只计 1 次
- [ ] 按 `Ctrl+C` 3 次，快捷键 TOP 10 里 `Ctrl+C` 显示 3 次
- [ ] 按 `Ctrl+V` 2 次、`Alt+Tab` 1 次，三者各自独立计数互不串号
- [ ] 敲 `Shift+A` 不产生组合键记录
- [ ] 按住 `Ctrl` 连按 3 次 `C`，`Ctrl+C` 记 3 次
- [ ] 热力图着色与按键 TOP 10 一致，且不含组合键数据
- [ ] 时间范围切换后所有指标（含快捷键）同步变化
- [ ] 暂停采集后按键与组合键都不再增长，继续后恢复
- [ ] 清空数据后各页回到空状态
- [ ] 导出两个 CSV 均可被 Excel 正确打开（中文不乱码）
- [ ] 关闭窗口后进程退出、采集停止
- [ ] 首次启动无需任何点击即开始采集，并弹出一次性 `MessageBoxW` 说明框（含「已经开始采集」
      「只记键码与次数，不记内容」「可随时暂停」三句），确认后不再弹
- [ ] 首次启动**不发系统通知气泡**，程序不出现任何托盘图标（v0.1 无托盘依赖）
- [ ] 勾选开机自启后 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 出现
      `"<exe 全路径>" --autostart`；取消勾选后该值被删除，无残留
- [ ] 带 `--autostart` 启动时窗口最小化、任务栏可见、采集已开始
- [ ] 把 exe 改名后，设置页提示「自启路径已失效」而不是静默失效
- [ ] `go vet ./... && go test ./...` 全绿，`gofmt -l .` 无输出
