# ⌨️ 键盘使用统计 v1.0.0 发布说明

发布日期：2026-11-10 · 第一个正式版本

一个只在本机运行的键盘使用统计小工具：统计你**按了哪些键、按了多少次、什么时间按的、
用过哪些快捷键**，用热力图和趋势图展示。**不记录你输入的任何内容，不联网。**

---

## ✨ 能做什么

- 🔢 **单键频次** TOP 10，带比例条
- 🎯 **常用快捷键** TOP 10（`Ctrl+C`、`Alt+Tab` 这类同时按下的修饰键组合）
- 🗺️ **键盘热力图**：一眼看出哪些键按得最多
- 📅 **时间范围**：今日 / 近 7 天 / 近 30 天 / 全部
- ⏱️ **活跃时长、日均按键、峰值、24 小时时段分布**
- 📤 **导出 CSV**，自己拿 Excel 分析
- 🔔 **托盘常驻**：关窗收进托盘，采集不中断
- 📁 **数据位置可选**：默认用户目录 / 便携模式（数据跟着程序走）/ 自定义目录

## 🔒 它绝对不做什么

| 不做 | 说明 |
|---|---|
| 🚫 不记录按键内容 | 库里只有「键码 + 次数 + 日期小时」，没有任何文本 |
| 🚫 不记录按键顺序 | 组合键只记「哪几个键同时按下」，不记先后 |
| 🚫 不记录窗口标题 / 应用名 | 不知道你在用什么软件 |
| 🚫 不联网 | 无任何网络代码，数据只在本机 |
| 🚫 不静默自启 | 自启默认关闭，需你手动勾选 |

## 🆕 相比 0.5.x 有什么变化

这一版没有新增功能，是把长期挂后台记录这件事**收口**：该修的都修完了。

- 🐛 **修掉「界面未响应」**：真因是窗口的消息循环没锁 OS 线程，
  跑几十秒后界面线程被调度器挪走，窗口再也收不到消息（视图卡住、托盘右键没反应）。
- ⚡ **数字几乎敲完就动**：刷新间隔 2 秒 → 0.5 秒，实测中位延迟 ~0.6 秒。
- 🖼️ **图标换掉**：标题栏 / Alt+Tab 不再是系统白板图标；托盘 16px 小图重画，不再糊。
- 🇨🇳 **安装向导汉化**：安装、升级、卸载全流程简体中文，没有「先选语言」那一页。

细节见 [CHANGELOG.md](../../CHANGELOG.md)。

## 🚀 安装 / 升级

**免安装版**：把 exe 放到固定目录，双击即可。数据默认在
`%LOCALAPPDATA%\keyboard-statistics\stats.db`。

**安装包**：双击 → 中文向导 → 可自选安装目录（装到 `D:\` 也行）→
勾选「便携模式」则数据放进程序目录下的 `data\`。

**从 0.5.x 升级**：直接跑 1.0.0 的安装包覆盖安装即可，**统计数据自动保留**
（安装器会先请程序正常退出，落库完成后再替换文件）。想换安装目录必须先卸载。

## ⚠️ 已知限制

- 🔐 **以管理员身份运行的窗口**（如任务管理器）里的按键统计不到，这是 Windows 权限隔离的必然结果
- 🚫 `Ctrl+Alt+Delete`、`Win+L` 这类系统保留组合任何键盘钩子都收不到
- 🛡️ 部分杀毒软件可能对全局键盘钩子报警（本程序不混淆、不加壳）
- ⏱️ 活跃时长是估算值：相邻按键间隔 ≤ 60 秒才算连续

## 🧪 这一版做过的验证

- `go test ./...` 全绿（168 个用例，8 个包），`go vet` / `gofmt` 干净
